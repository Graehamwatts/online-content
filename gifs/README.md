# GIF Library — organized by pipeline

Reusable (non-personalized) GIFs only. Each pipeline has its own subfolder.
Lipdub GIFs are per-lead, auto-generated by the pipeline, and never stored here.

Filename convention:  `<pipeline>-day<N>-<variant>.gif`
Live URL once pushed:  `https://graehamwatts.github.io/online-content/gifs/<pipeline-folder>/<filename>`

Each GIF: 3–4s silent loop, vertical, play-button overlay, "TAP TO WATCH" caption.

Pipelines:
- new-leads/  (defined — see its README)
- buyer/      (to define when we build the Buyer pipeline)
- seller/     (to define when we build the Seller pipeline)
- investor/   (to define)
- past-buyers/  (to define)
- past-sellers/ (to define)
- lost/       (to define)
