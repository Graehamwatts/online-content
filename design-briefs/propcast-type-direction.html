Recommendation

  • Pick System A ("Signal") — Space Grotesk (display) + Inter (UI) + JetBrains Mono (data). It's distinctive enough to own, neutral enough to never fight the 3D scenes, and Inter keeps the actual product screens rock-solid.
  • If you want the safest single-family route, System B. If you want maximum brand personality and trust the design discipline, System C.
  • All three: set the mono font as the official "data voice" — every ZIP, stat label, and machine annotation across landing, dashboard, and reports uses it. That texture is what makes PropCast feel like an instrument, not a template.
  • Weights: Display 500/700 only. UI 400/500/600. Mono 400/600. Nothing else — weight discipline is crispness.
