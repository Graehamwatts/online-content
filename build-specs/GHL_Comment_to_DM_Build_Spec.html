Comment-to-DM Automation in GoHighLevel

The native GHL replacement for ManyChat. Built as a Workflow, no extra subscription, leads land straight in the CRM. ManyChat stays as a backup only.

Verdict: it matches ManyChat for our use case

Confirmed capable (per GHL's own docs). GHL natively does: keyword-triggered comment detection → auto-DM the commenter → interactive buttons & quick replies ("Are you buying or selling?") → a separate branch per answer → tag, pipeline move, and enrollment into the New Leads sprint. That is the full flow we run in ManyChat, and it's already included in GHL.

How it's built — it's a WORKFLOW

Built in Automation → Workflows → Create Workflow → Start from Scratch. Not a separate tool — a normal GHL workflow with an Instagram/Facebook trigger.

  1. Trigger: "Instagram Comment on Post" (Facebook has the same). Under Filters, set keyword match: Contains Phrase or Exact Match (e.g., "BUY", "SELL", "HOME"). Toggle Track First Level Comments Only on.
  2. Action: Actions → Communication → Instagram Interactive Messenger. Reply Type = Reply to Comment via DM (takes the public comment private).
  3. Message + interactive controls: write the DM, then add Quick Replies (one-tap, e.g., "Buying" / "Selling") or Buttons (persistent, e.g., "Book a call" / "See listings").
  4. Branches (auto-created): each quick reply/button makes its own branch. In the "Buying" branch → tag Buyer, add to Buyer pipeline / New Leads sprint. In "Selling" → tag Seller, route accordingly.
  5. Wait + Default Timeout: each messenger action needs a Wait step (default 1 min, editable). If no reply, the contact falls into the Default Timeout branch (send a nudge, tag "No Response").
  6. Capture: in each branch add Create/Update Contact + tag Source: IG Comment so the lead is in the CRM and flows into the New Leads automation.

Shortcut: GHL also ships a pre-built "Instagram Comment Automation" Workflow Recipe John can start from instead of building from scratch.

Prerequisites (do these first or the trigger won't fire)

  1. Connect the Facebook Page + Instagram Business account in GHL → Settings → Integrations.
  2. In Meta Business Suite, enable the DM-keyword setting so GHL is allowed to auto-reply.

Honest limits (mostly Meta's rules — they hit ManyChat too)

• 24-hour messaging window: automated DMs only within 24h of the user's last interaction (a Meta rule, not a GHL weakness — ManyChat has it too).
• 7-day comment-reply window: the comment→DM reply must send within 7 days.
• Quick Replies can't share a message with an attachment — send the attachment in a separate step.
• Where GHL is genuinely lighter than ManyChat: ManyChat's flow builder is more visual/mature and supports more channels (WhatsApp, Telegram, TikTok) and flow A/B testing. For our comment→DM→qualify→capture, GHL is plenty. Keep ManyChat as backup if we ever need those extras.
