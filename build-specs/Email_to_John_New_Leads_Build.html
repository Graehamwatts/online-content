How to add any step (the mechanic)

Click the "+" at the end of the last node → the Actions panel opens on the right → type the action name in the search box (or scroll to it) → click it → fill the fields → Save action. That's the loop for every step below.

One decision first: Buyer vs Seller split

The sprint has buyer and seller versions of most messages. Recommended structure: right after Step #2 (the Wait), add an If/Else that checks the lead's type, then build the touches inside each path.
  • Add action → search "If/Else" → Branch 1 condition: Contact Tag → is → buyer (or your Buyer tag). Name it "Buyer". The Else path is "Seller".
  • Build the steps below inside the matching branch. Where you see BUYER / SELLER, use that copy in that path. Steps with no label (waits, calls, routing) are identical in both paths.
If you'd rather ship v1 faster: skip the branch, build it linear, and use the BUYER copy as the default — we'll split it after it's tested. Your call; the branch is cleaner long-term.
