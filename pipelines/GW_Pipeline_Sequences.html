Every pipeline draws from these tools. Auto = fires through GHL/N8N automatically. Manual = Adrian or Graeham action required.

Live Call

Adrian or Graeham dials directly. Always the first attempt on any new lead or re-engagement. Most powerful touch — use it at the highest-intent moments.

Voicemail Drop

Slybroadcast via N8N trigger — fires within 2 minutes of a missed call automatically. Pre-recorded message from Graeham. Do NOT use GHL native voicemail — it's unreliable.

Lipdub GIF MMS

Personalized video — Lipdub changes the name Graeham says while keeping the same recording. Sent as animated GIF thumbnail via MMS with calendar link below. Use surgically — has a per-video cost. Post-close can be fully automated: N8N fires on close → Lipdub API generates → sends via MMS.

Static Video GIF MMS

Pre-recorded "feels personal" video with no name called out ("Hey, I wanted to personally reach out…"). Sent as animated GIF via MMS + calendar link. Jason builds a library of 6–8 of these. Free to send at scale — use wherever Lipdub isn't worth the cost.

HeyGen Video Email

AI avatar video for market updates, process explainers, buyer/seller guides. Embedded as GIF thumbnail in email. Cheaper than Lipdub for educational content at scale. Jason and Ellie produce the library.

AI Agent Text

GHL AI sends automated texts. Mid-drip check-ins, listing alerts, GIF casual touches. Fires automatically — Adrian only steps in if lead responds and escalates.

AI Agent Call

GHL AI outbound call on scheduled day. If no answer, Slybroadcast VM fires via N8N automatically. Adrian steps in only if lead engages and wants a human.

ManyChat Messenger

Meta ad leads ONLY. When someone submits a FB lead form, ManyChat fires an instant Messenger message (80–90% open rate). Qualifying questions → phone captured → N8N → GHL → Adrian notified. Set up once by John, runs forever.

Email (GHL)

GHL email builder. Educational content, CMAs, market updates, testimonials, process guides. Always include a video GIF thumbnail (HeyGen or YouTube static) and calendar link where relevant.

Manual Task

Adrian reviews and takes action. Routing decisions, pipeline moves, live calls, review asks, showing arrangements. Always log outcome as a Note in GHL immediately after completing.
