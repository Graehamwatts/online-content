② Videographer Packet — for Wesley

LONG shoot (~4-5 hrs). Shoot wide/flexible; name each file with its Clip ID, e.g. GARDEN-L02_both.mp4
Quick word key: Wide=whole house/room · Medium=waist-up · Close-up=one detail · Push-in=camera eases toward subject · Gimbal walk=operator walks with a stabilizer (smooth) · Pull-back=camera backs away to reveal more.
Why this order: shoot the property exactly like a buyer would walk it, once, in one direction. Drone up top and out of the way first, then curb, then front yard, then straight through the door and through the house room-by-room following the actual floor plan, then out the back, then the detached garage last since it sits off to the side. Never double back to a location already shot.

Plan the window: Block A is Wesley solo (~3 hrs) — drone, neighborhood sweep, all exteriors at golden hour, every interior, details, optional twilight, in the geographic order below. Block B (~2 hrs, if Graeham makes it) is talking-head + POV layered onto the same locations, not a re-walk. Access: confirm access + a tidy interior first.

Drone airspace: East Palo Alto sits under Palo Alto Airport (KPAO) controlled airspace — clear LAANC / check B4UFLY before flying. No authorization? Skip the drone shots and get elevated / high-angle ground shots of the lot instead.

If Graeham can't make it: every listing shot below (a) is composed in full so Wesley shoots it solo from this brief, no live direction needed. Talking-head lines in packet ③ render later from the digital_twin avatar off this same script — Wesley doesn't need to capture any of those on this trip unless Graeham is there for Block B.
